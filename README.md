# Progamins

Construyo proyectos web, APIs y aplicaciones mientras sigo aprendiendo. Perú 🇵🇪

---

## Sobre mí

Soy desarrollador full-stack de Perú. Desde 2023 construyo proyectos completos: la interfaz, la API, la base de datos y el despliegue. La mayoría de lo que hago es web — React, Node.js, PHP, MySQL — pero también tengo apps Android publicadas y varios experimentos sueltos.

Me gusta aprender haciendo. Cada proyecto de acá es algo que construí de punta a punta, con sus aciertos y sus errores, y que en varios casos sigue funcionando para alguien real.

Uso herramientas de IA como parte de mi flujo de trabajo, sobre todo para prototipar, investigar y acelerar partes del desarrollo. Los proyectos siguen siendo míos: los diseño, los construyo y los mantengo.

## Proyectos destacados

### [Maison Rosas](https://github.com/progamins/webhermanos) — [demo](https://webhermanos-client.vercel.app)

Tienda online para una pastelería real: catálogo, pedidos con seguimiento, panel de administración con roles y notificaciones en tiempo real. Funciona como PWA, así que también se puede usar sin conexión. Es un proyecto de verdad, para un negocio de verdad: se usa todos los días.

`React` `TypeScript` `Express` `MySQL` `Docker`

### [iestp](https://github.com/progamins/iestp)

Sistema de gestión académica hecho en PHP. Los estudiantes pasan asistencia escaneando un código QR (con control para evitar duplicados) y el sistema maneja horarios, unidades didácticas, justificaciones, pagos y reportes PDF.

`PHP` `MySQL` `FPDF`

### [proceso-nodes](https://github.com/progamins/proceso-nodes)

La API REST que acompaña a la gestión académica: estudiantes, notas, horarios y justificaciones con subida de imágenes y códigos QR. Autenticación con JWT y bcrypt, rate limiting y tests automatizados.

`Node.js` `Express` `MySQL`

### [OpenMedia Downloader](https://github.com/progamins/opendowload) — [demo](https://opendowload.vercel.app)

Un experimento de arquitectura: la interfaz corre en Vercel (React + Vite) y se conecta por un túnel de Cloudflare a un servidor Express que corre en la PC del usuario. Descarga videos con yt-dlp y FFmpeg, muestra el progreso en tiempo real con SSE y guarda los archivos directo en el disco. El tipo de proyecto que hago solo para ver si la idea funciona.

`React` `TypeScript` `Vite` `Express` `SSE` `yt-dlp + FFmpeg`

### [aplicativo-java](https://github.com/progamins/aplicativo-java)

App Android en Kotlin y Jetpack Compose con su propia API: autenticación con JWT y refresh tokens, backend en Node.js + Express y Docker para levantar todo junto. La base de datos puede ser MySQL o SQLite.

`Kotlin` `Jetpack Compose` `Node.js` `Express` `JWT` `Docker`
